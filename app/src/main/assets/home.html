WebView Guard

This prototype runs web content packaged with the app, while denying HTTP and HTTPS requests made by this WebView.

What this prototype does
  • Allows local HTML, CSS, JavaScript and packaged assets.
  • Blocks remote pages and remote resources, including images.
  • Does not request network permission.
Important limitation

This is a standalone test host, not a replacement for Android's system WebView provider. Other apps will continue using their existing WebView unless the operating system or a privileged/root-level integration is changed.
